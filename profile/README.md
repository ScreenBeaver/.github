## Product videos without touching your screen

Screen Beaver is the **MCP-powered demo studio** for founders, PMs, and developers. Agents drive the walkthrough, the studio polishes the take, and export stays on your machine.

| Capture | Polish | Export |
| --- | --- | --- |
| Display, window, browser tab, or Android over USB | Auto zoom, cursor effects, captions, SFX, scene FX | Local H.264 MP4 — nothing uploaded to encode |

Built for people who ship software and need the story to look as intentional as the product — without opening a full editing suite every Tuesday.

## What you get

- **Hands-off MCP capture** — Connect Cursor, Claude Code, Windsurf, Codex, Copilot, and other MCP clients. Your agent walks the product; Screen Beaver films.
- **Editorial polish** — Soft zooms on glances, stronger punches on typing and menus, smooth cursor follow, captions that work on mute.
- **Manual studio when you want it** — Same timeline tools without an agent: backgrounds, crop, camera PiP, captions, VO helpers, and more.
- **Android USB** — Mirror and record phones with portable ADB, 9:16 frames, and the same zoom / caption polish as desktop.
- **Local-first export** — Crisp MP4 on your machine. Optional network helpers (voice, music) stay opt-in — never required to finish a take.

## Quick start

**1. [Download from Microsoft Store](https://apps.microsoft.com/detail/9P89CCNBVMVV)** — install the Windows studio and leave the app running.

**2. (Optional) Add MCP** so agents can drive capture:

```bash
npm i -g @screenbeaver/mcp
```

**3. Wire your agent** (Cursor / Claude `mcp.json` example):

```json
{
  "mcpServers": {
    "screenbeaver": {
      "command": "npx",
      "args": ["@screenbeaver/mcp"]
    }
  }
}
```

Ask your agent for a launch video in plain language. Review the timeline, then export locally.

Prefer the mouse? Record and edit by hand — MCP is the unlock, not the only path.
